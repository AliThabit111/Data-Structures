# Introduction to Data Structures

## 📌 What is a Data Structure?
A **Data Structure** is a specialized format for organizing, managing, and storing data to enable efficient access, modification, and processing.

### Core Operations:
* **Access:** Retrieving a specific element by its index or reference.
* **Search:** Locating a specific value or key within the structure.
* **Insertion:** Adding a new element at a defined position.
* **Deletion:** Removing an existing element from the structure.

---

## 🗂️ Classification of Data Structures

### 1. Primitive Data Structures
Basic building blocks provided directly by programming languages to represent single, atomic values in memory:
* `int` (Integer)
* `float` / `double` (Floating-Point Numbers)
* `char` (Characters)
* `pointers` (Memory Addresses)

### 2. Non-Primitive Data Structures
Complex structures created by combining primitive types to manage collections of data.

#### A. Linear Data Structures
Elements form a sequential order where each item is connected to its previous and next neighbors:
* **Arrays:** Contiguous memory storage with fast indexed access.
* **Linked Lists:** Nodes containing data and pointers to the next node.
* **Stacks:** LIFO (Last In, First Out) access pattern.
* **Queues:** FIFO (First In, First Out) access pattern.

#### B. Non-Linear Data Structures
Elements are arranged hierarchically or interconnected without a single linear sequence:
* **Trees:** Hierarchical structure with a root node and parent-child relationships.
* **Graphs:** Network of vertices (nodes) interconnected by edges.
